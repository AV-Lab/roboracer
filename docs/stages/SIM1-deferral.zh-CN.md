## 现在保留与后续补齐

| 现在必须保留 | 可以后置，但保持未验证 |
| --- | --- |
| 目标车速／转角接口及可用反馈、单位／符号验证 | 真实采集时刻／序号和严格源数据新鲜度 |
| 独立指令监督、请求自身超时、非有限值／越界拒绝 | 最终发送端失效后的接收端自动过期与停车 |
| 经确认的速度、转角、变化率、持续时间及空间范围 | 完整独立圈数／碰撞／越界评分 |
| 通信仍可用时的正常停车、失效处理与明确终止状态 | 无人值守复位、五起点、静态障碍自动设置 |
| 进程归属、故障记录、有限仿真会话的终止措施 | 对应后续阶段的完整验收与性能结论 |

接收时间只能证明消息何时到达，不能证明传感器何时采集。即使消息持续到达，也可能无法发现源端重复旧数据；这项限制必须写入演示结果。

独立监督进程存活且通信可用时，可以处理算法退出、无效输入等并发送停车请求。如果监督进程／最终通信路径失效，而模拟器尚未证明会自行停车，演示只能判失败并终止自有模拟器进程。**这是仿真故障处置，不能记作制动通过，也不能作为实车停车方案。** 实车硬件停车继续保持独立。

短程运动和正常停车仍须实际验证。没有依据猜测控制语义、忽略反馈或给出任意速度上限。批准后置安排也不自动批准运动；仍先确认具体数值运动协议。
