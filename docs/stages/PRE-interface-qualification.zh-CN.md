第一轮人为增加了 100 ms 回复延迟，第二轮未增加；两轮配置不同，不能把频率差全部归因于 TF 修复。短时间 RSS 采样也不能证明长期不存在内存泄漏。

八类消息为油门、转向、左右编码器、IPS、IMU、LiDAR、前摄像头。全部 240 帧的油门、转向和编码器反馈为零。协议三位小数精度下，位置为 x=0.740–0.741 m、y=3.158 m、z=0.059 m。四段观测的首帧位置相同，但这不能证明确定性重放，也不是制动距离／停车容差。

LiDAR 每帧 1081 个采样点，首帧样本中 1035 个有限距离；相机解码为 1280×720 RGB。四段观测各取首帧，转换后的 float32 距离数组和 RGB 字节均在实际 ROS 接收数据中找到一致结果。AVLite 观察进程仅导入并接收数据，没有执行插件或控制算法。

API 中的 `LIDAR Scan Rate = 20.000` 只是上报设置，不能当作实测 API 频率或独立采集频率。这些静止短测不是 M1／M2 性能验收。

## 安装包几何与源码差异

通过独立分析环境中的 UnityPy 1.25.3 只读解析，提取了安装包 `Data/level0` 的内置类型、18 个碰撞网格及 120 个脚本身份。未保存或修改 Unity 资源。分析环境最初受继承的 ROS PYTHONPATH 影响而出现 pip check 失败，去除该路径后独立检查通过；两次结果均保留。

已确认：

- 序列化场景中 Proto Track 激活，Berlin Track 未激活；Proto 是候选 C0，尚未验证运行时赛道切换。
- Rigidbody 质量约 3.47 kg，WheelCollider 半径约 0.059 m。
- 前后轮 transform 的纵向距离约 0.330 m；命名 axle-center 的纵向距离约 0.331 m。它们与历史控制器的 0.324 m 轴距参数、0.0325 m 半径字段存在差异，不能混用。
- 历史 IPS 坐标变换为 `(Unity.z, −Unity.x, Unity.y)`。安装包后轴初始位置按此变换约为 `(0.740, 3.160, 0.060)`，与悬架稳定后的遥测接近，但运动中的符号、参考点和完整变换仍未验证。
- 多数自定义 MonoBehaviour 缺少完整类型树，解析失败已记录；没有根据无类型字节猜测控制器参数。
- Devkit 前轮 TF 仍含 `0.141537/0.0765` 常数，不能作为已标定 F1TENTH 运动学。
- 实际 ROS `time_increment` 约为 0.000138889 s，来自 `(1 / scan_rate) / 360`，不是已验证的逐束采集时间，不应据此进行运动去畸变。

证据：[几何汇总](../../artifacts/preflight/20260928T124339Z/installed-geometry-summary.json)。网格提取不等于完成接触、整车越界或有效圈数评分器，也没有完成地图和参考路径导入。

## 需要确认的路线

原计划明确要求：唯一指令发布进程退出或卡死时，存活的下游接收端必须实施已验证的超时停车，否则该项保持阻塞；重复发布也不得刷新原采集的新鲜度。当前没有降低这些标准。

| 方案 | 收益 | 成本、风险及计划影响 |
| --- | --- | --- |
| **A：准备独立 AutoDRIVE 仪表化构建，推荐** | 保留现有验收目标及 AutoDRIVE／Humble／ICP 方向；补充可验证的采集身份／时间、下游超时、评分事件、复位／起点／静态场景控制。 | 增加模拟器构建与维护范围。需先核对完整官方源码、资源及 Unity 工具链。本机 PATH 和检查的常见目录未找到编辑器；下载、许可可用性、构建成功与物理一致性均未验证。 |
| B：保留当前二进制，明确修订相关验收 | 避免 Unity 构建依赖，使用已经跑通的数据链路。 | 接收新鲜度弱于采集新鲜度；进程终止不等于制动；部分场景覆盖可能仍不可用。属于降低或拆分原验收，必须明确批准，不能仍宣称原 PRE／发布范围全部完成。 |
| C：保持计划，等待合格的官方版本／API | 避免维护自定义构建，也不降低标准。 | 等待期间相关交付持续阻塞，不能保证时间。 |

推荐 A，但**当前仅请求批准 PRE 准备范围的扩展**：检查完整固定源码和构建前置条件、评估独立工具链可行性、提交最小改动的接口／文件／验收修订方案。选择 A 不等于批准立即修改模拟器、获取编辑器许可、安装编辑器、发送运动指令或接受修订计划。

候选改动职责包括：传感器级采集序号／时间及仿真步信息；与独立监督进程互补的模拟器端指令有效期；停用状态下的复位／起点／静态场景配置；与驾驶输入隔离的真实状态、碰撞和进度输出。保留当前安装包，不改 AVLite 核心，不改车辆物理参数，不改“目标车速＋转角”接口。可行性明确后，再提交修订计划及数值运动协议。
