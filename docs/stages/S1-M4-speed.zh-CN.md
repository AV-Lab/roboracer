# S1-03 阶段 M4 — 闭环速度

日期：**2026-10-05**。运行：`20261005T152922Z-m4`。[英文报告](S1-M4-speed.md)。方案：[s1-03-controller-proposal.md](../planning/s1-03-controller-proposal.zh-CN.md)，v0.3。批准：“yes run M4 and M5”；v0.3 阈值，“yes rerun M4”；释放 GPU，“You can kill the Python processes to free the GPU memory”（[记录](../planning/s1-motion-approval.json)）。

**M4 通过（第 5 次试验）。** 车辆第一次由 AVLite 经目标速度路径驱动：
- AVLite `SpeedStepController` 发出目标速度请求；
- 插件桥接把请求送到监督器；
- 监督器的速度环（D5 v0.3）用它自己订阅得到的编码器速度（D4 A）把每个目标速度换算成油门；
- 守卫执行该油门。

在直道上、转向恰为 0 时，速度能跟踪 0.1 / 0.2 / 0.3 m/s，没有制动抖振。从 0.3 m/s 停车用时 0.34 s；人为制造的反馈中断会先切断油门，再使监督器进入抑制状态。

## 结果（第 5 次试验）

| 目标 | 最后 1 s 平均速度（需在 ±0.05 内） | 超调（≤ 0.1） | 制动次数（≤ 2） |
| --- | --- | --- | --- |
| 0.1 m/s | 0.109 | 0.027 | 0 |
| 0.2 m/s | 0.212 | 0.037 | 0 |
| 0.3 m/s | 0.311 | 0.027 | 0 |

- **从 0.3 m/s 停车：** 0.34 s（上限 1.5 s）。**最终停车：** 0.13 s。
- **反馈过期**（监督器从第 12 s 起忽略编码器反馈）：0.50 s 后油门为 0（上限 0.6 s + 一帧），0.80 s 后进入抑制，此后不再转发任何请求。恰好一次零输出下的最终 `lease-expired`。
- **反馈时龄**（中断前）：p50 211 ms，p95 299 ms，最大 324 ms。遥测帧周期：p50 210 ms，最大 241 ms。
- **延迟链（D7）**，各段按各自的时钟计量：

  | 区段 | p50 | p95 | 最大 |
  | --- | --- | --- | --- |
  | AVLite tick → 请求生成 | 0.29 ms | 0.37 ms | 0.51 ms |
  | 生成 → 监督器决策 | 0.12 ms | 0.15 ms | 0.21 ms |
  | 生成 → 守卫接受 | 145 ms | 185 ms | 238 ms |
  | 接受 → 首个施加步（仿真时间） | 1 ms | 1 ms | 1 ms |

- **行驶与路径：** 直线行驶 2.26 m，低于 2.5 m 上限。守卫输出保持在油门 ≤ 0.07、转向 0 之内，无守卫 fault 或拒绝。
- **请求：** 转发 171 个；中断后另有 16 个按设计被拒为 `inhibited`，1 个被拒为 `feedback-lost`。
- **进程与播放器：** 所有子进程退出码为 0，端口已释放，播放器 604 个文件均未改变。

## 各次尝试（全部保留；6 次行驶试验上限中用了 2 次）

| 尝试 | 结果 | 原因与处理 |
| --- | --- | --- |
| 0 | 无运动 | 监督器无法导入 `rclpy`：运行器替换了 `PYTHONPATH`，而不是在其后追加。已修正。 |
| 1 | 无运动 | 播放器在启动时段错误。当时 GPU 几乎已满（见第 4 次）。 |
| 2 | 无运动 | “尚无反馈”被当作“反馈丢失”，监督器在第一个请求时就自行抑制。已修正。 |
| 3 | 已运行；跟踪失败 | 0.4 s 的过期阈值低于实测反馈时龄（最大 564 ms），导致频繁硬制动。方案 **v0.3** 把它提高到 0.6 s，丢失阈值提高到 0.9 s；已获你确认。 |
| 4 | 已运行；被守卫停下 | 两个 `thellmbook` Jupyter 内核占用了 10 GB 中的 8.6 GB GPU 显存，导致遥测变慢（帧间隔最长 648 ms，渲染 34 Hz）。守卫租约过期并按设计停车。经你同意，我终止了这两个内核（SIGTERM），GPU 占用降到 874 MiB。 |
| 5 | **通过** | 渲染 60 Hz，帧周期 210 ms。 |

方案的修订记录载有 D5 的演变：v0.2 数值，随后由 M3b 得到 K = 5.02，再到 v0.3 阈值。
