# S1-03 阶段 M5 — 反应式基线 A 在赛道段上运行

**M5 第一次试验即通过。** 这是 S1-03 的演示：反应式基线 A，即 AVLite 中的 `GapFollowController`，通过 AVLite 自身的执行路径沿赛道段驾驶车辆：
- `SyncExecuter` 以 10 Hz 在固定快照上运行，真值位姿带标签且只用于监控；
- 插件桥接把每个请求送到监督器；
- 监督器的速度环和精确转向换算生成命令；
- 守卫执行该命令。

车辆第一次在行驶中转向。它在 21 s 内行驶了 6.06 m，随后请求零速并停车。

## 结果（第 1 次试验）

| 项目 | 结果 |
| --- | --- |
| 结束条件 | 21.0 s 后路径达到 6 m（6.06 m）；无中止 |
| 速度 | A 给出的目标速度为 0.27–0.30 m/s；编码器速度最高 0.35 m/s，低于 0.5 m/s 中止阈值 |
| A 请求的转向 | −0.068 到 0 rad（通道向左变宽时略微向右修正；上限 ±0.35 rad） |
| 余量 | 侧向 ≥ 0.28 m（低于 0.15 m 中止）；正前 ±10° ≥ 1.49 m（低于 0.5 m 中止） |
| 最终停车 | 零请求后 0.17 s 停下；恰好一次零输出下的最终 `lease-expired` |
| 监督器 | 转发 267 个；执行的规则：`control` 210 次，`target-zero` 55 次，`no-feedback-yet` 2 次；无反馈过期事件 |
| 守卫 | 无 fault，无拒绝；输出在油门 ≤ 0.07、\|转向\| ≤ 0.668（0.35 rad）之内 |
| 延迟链（D7，p50 / p95） | tick → 请求生成 0.92 / 1.46 ms；生成 → 监督器决策 0.11 / 0.16 ms；生成 → 守卫接受 128 / 176 ms；接受 → 首个施加步 1 ms（仿真时间） |
| 进程与播放器 | 所有子进程退出码为 0；端口已释放；播放器 604 个文件均未改变 |

**对后续阶段的观察。** A 朝最深的自由方向行驶，而不是朝通道中央。通道向左变宽时，右侧余量从 0.54 m 降到 0.28 m。这在本阶段的限制以内，但完整跑圈（S1-05/06）需要加入居中项，或更严格的侧向余量限速规则。此处仅记录，不作修改。
