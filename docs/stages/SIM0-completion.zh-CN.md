# SIM0 — 修订后 P0 静止验收与基线报告

日期：**2026-10-05**。运行：`20261005T052025Z-p0`。[English report](SIM0-completion.md)。

**在修订后的 P0 下，SIM0-03 与 LNX-04 通过。SIM0-B06 作为已记录的、继承自原模拟器的特性关闭，而不是作为已修复的缺陷。** 源码构建的 F1TENTH 播放器完成了两次全新进程、各 60 秒的零指令观测：八个话题全部送达，首帧扫描与图像内容一致，自有进程干净退出。本报告即 SIM0-04 的基线发布；**SIM0-04 须经你的阶段评审后才勾选**，该评审同时是 SIM1 的进入关口。

## 1. 已记录的决定

用户于 2026-10-05 选择方案 A（“A, go ahead”）：

- **停止 SIM0-B06 的根因调查。** 被动蠕移（零指令、零反馈、零编码器时，沿车辆前向约 3.4 mm／60 s）在**未修改的已安装厂商播放器**中同样出现（报告值 3／4 mm，重建版 3／3 mm，见[漂移研究](SIM0-neutral-drift.zh-CN.md)）。因此它是继承自 AutoDRIVE／Unity 车辆的行为，而非构建回归。四轮诊断（[运动学](SIM0-kinematics.zh-CN.md)、[接触](SIM0-contacts.zh-CN.md)、[Floor A/B](SIM0-floor-contacts.zh-CN.md)、[位姿审查](SIM0-pose-review.zh-CN.md)）刻画了该现象，但未改变这一结论。它与基于滑移、缺乏真正静摩擦的 WheelCollider 轮胎模型相符，但该机理**未经证明**。
- **修订 P0 位置规则**：由“任何报告位置变化即终止”改为自首个完整帧起、覆盖 60 秒窗口的**包含式 10 mm 位移上限**。该上限与此前获批诊断运行所用一致。精确零指令／反馈守卫、任何编码器变化守卫及 P0 其他所有要求**保持不变**。
- **取代已获批但未执行的位姿追踪实验**（`20261001T130821Z-pose-trace`）。其准备工作（派生副本、`PoseTrace.cs`、控制器预览补丁、40 项测试通过、API 编译、主机预检）予以保留；未进行任何追踪构建或运行。

上限充分的理由：蠕移速率约 0.06 mm/s，比目标竞速速度低约五个数量级，也远低于 PRE-03/04 与 S1 所测的厘米级定位与制动量。对物理的“修复”会使重建版偏离厂商播放器，而 SIM0 的目的恰恰是复现该参考。若今后某场景需要静止保持保证（例如长时间起步前等待），须按其自身容差重新评估该蠕移。
