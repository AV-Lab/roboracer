# S1 运动阶段 M1 — 油门符号与最小直线脉冲

日期：**2026-10-05**。运行：`20261005T115944Z-m1`。[英文报告](S1-M1-throttle.md)。协议：[s1-motion-protocol.md v0.1](../planning/s1-motion-protocol.zh-CN.md) §3–§4。批准：“approve M1 as drafted”（[记录](../planning/s1-motion-approval.json)）。

**M1 通过。** 这是第一批使车辆运动的命令：四个前进油门脉冲，转向恰为 0，每个脉冲都从静止开始，之后回到零油门（制动）。

- **符号：** 正的归一化油门使车辆**沿其 +x 方向前进**，横向偏离 0 mm，航向变化 0°。两个编码器都**增加**。
- **扭矩：** 施加的扭矩恰为每轮 85.6 N·m × 油门 / 4（CAWD）。
- **停车：** 每个脉冲之后，D1 补丁使全部电机扭矩为 0 且制动施加。车辆在请求生成后 0.35–0.58 s 内停下（上限 1.5 s）。

车辆响应比协议中的理想力估计弱约 20 倍。所有脉冲（包括可选的 0.02）都远低于 0.5 m/s 和 0.5 m 的上限。**M2 未获授权，也未运行。**

## 1. 执行方式

- **请求源。** 标定源由已提交的快照事件驱动。自 D3 起，快照在桥接 50 ms 节拍回复之前提交。因此油门请求在第 *k* 帧发出，在该帧的回复中转发，并在第 *k+1* 帧被零取代：每个脉冲恰为**一个遥测间隔，0.199–0.201 s**。协议草案为 0.25 s；D3 之后遥测周期约为 0.20 s，实际施加时长取自守卫的逐步追踪。
- **顺序。** 0.002 → 0.005 → 0.01 → 0.02。每一步都要求：
  - 之前的每个脉冲都在两项上限之内；
  - 上一个脉冲的峰值速度按油门线性外推到下一个油门后，仍在速度上限之内。这是一个只会跳过运动的保守附加规则。

  每个脉冲都从静止开始（IPS 速度 < 0.02 m/s），且距上一个脉冲至少 3 s。
- **工作区与中止监控（§3）。** 脉冲之前：出生偏移 0 mm，正前 ±15° 余量 2.26 m，两侧 0.74 / 0.54 m。全程由标定源检查：速度和行驶上限、航向 > 10°、横向 > 0.15 m、前向余量 < 1.0 m、侧向余量 < 0.25 m、守卫 fault、超过 0.6 s 无快照。桥接子进程另在总位移达到 2 m 时安全失败。
- **命令界限。**
  - 监督器阶段 `m1` 配置允许油门 {0, 0.002, 0.005, 0.01, 0.02}，转向恰为 0；只有提供批准记录时才会开启。
  - 运行器按该配置检查每个发出的守卫请求，只接受取这些值的油门反馈（3 位小数），且转向反馈恰为 0。
  - 授权运动需要 SIM1-03 构建记录（D1）以及一致的 `GameAssembly.so` 哈希。
  - 武装时间限制为 18 s，试验以停止发送结束，守卫租约在零输出下过期。

**响应映射。**
- 对 0.20 s 脉冲，峰值速度约为每单位油门 4.7 m/s，行驶距离约为每单位油门 0.95 m，两者大致线性。
- 协议中的理想力估计（0.01 → 约 4 m/s²，0.2 s 后约 0.8 m/s）高估了约 20 倍。该估计忽略了车轮惯量和接触损耗，现以实测值取代。
- 速度基于 IPS：分辨率 1 mm，帧间隔约 0.2 s。它是真实峰值速度的下界，0.002 处于分辨率极限。

**交叉检验。**
- **编码器：** 两个编码器都增加 +180 tick、+0.589 rad。该转角乘以 0.059 m 的轮碰撞体半径为 34.8 mm，而 IPS 行驶为 35 mm。因此编码器角度即车轮转角（rad），前进为正，每转约 1,920 tick。
- **带制动的释放（D1）：** 每个脉冲之后，四个电机扭矩恰为 0，四个制动均为 85.6 N·m（每次检查 2,000 步）。守卫没有 fault。
- **停车：** 四个脉冲都满足停车鉴定。请求生成后 0.58 s 内速度降到 0.02 m/s 以下，每个脉冲的总行驶（≤ 19 mm）都小于 0.15 m 上限。
- **命令路径：** 85 个标定请求全部转发。监督器处的观测时龄为 97 / 110 / 120 ms（p50 / p95 / 最大），因为请求现在在快照提交时立即发出。守卫检查通过：武装、无拒绝、无 fault、恰好一次零输出下的最终 `lease-expired`、解除武装。共 43,095 个追踪步，转向全部恰为 0。
- **进程与播放器：** 试验在 52 s 内自行结束，5 个子进程退出码均为 0。端口已释放，播放器 604 个文件均未改变。本次试验总行驶 35 mm，上限 3 m。
