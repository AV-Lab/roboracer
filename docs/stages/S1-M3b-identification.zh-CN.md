## 3. 分析修正（已保留），同时修正 M3

第一次 M3b 分析判为“无平台”（`m3b-trial1-analysis-v1-flagged.json`）。它的“保持期间”帧包含了油门结束*之后*采集的第一帧，那一帧已经在制动（例如 0.152 → 0.139 m/s）。平台判断和稳态速度平均值都用到了这一帧。

修正方法：
- 只统计油门施加期间采集的帧；
- 稳态速度取第一帧（稳定帧）之后的平均值；
- 这些帧彼此相差在 5 % 以内即判为平台。

用修正后的分析重新运行 **M3** 的试验（`m3-trial4-reanalysis-v3.json`），得到的增益为 **5.02 / 5.03 / 5.02**，而不是 4.89–4.91。M3 的稳态速度为 0.0251 / 0.0503 / 0.1005 m/s。M3 的其他结果均不变。[M3 报告](S1-M3-identification.zh-CN.md)现已注明这一修正。
